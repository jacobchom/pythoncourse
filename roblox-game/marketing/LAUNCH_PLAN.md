# Launch and Advertising Plan: Sky Jump

No plan guarantees a game goes viral. What this plan does is make sure the game gets enough eyes that Roblox's recommendation algorithm can tell whether players stay. Roblox mainly promotes experiences based on **retention, session length, and how many visitors become players**. Ads and TikToks only buy you that first test.

## 1. Store page (copy-paste)

**Title:** `[NEW] Sky Jump: +1 Jump Every Second`
(Drop `[NEW]` after 2 weeks. Use `[UPDATE 1]` style tags when you ship updates.)

**Description:**
> Every second you jump HIGHER. 🦘
> Climb 11 floating islands to reach THE SUMMIT 🏆
> Rebirth to grow even faster ⚡
>
> 🎁 Daily rewards
> 💬 CODES: RELEASE · SKYHIGH
> 👍 Like + ⭐ Favorite for new codes! 1KLIKES code at 1,000 likes
>
> Updates every week!

**Genre:** Obby & Platformer. **Max players:** 12 (full servers look busy, and seeing other people jumping is part of the fun).

## 2. Art (the thumbnail does most of the work)
- **Icon (512×512):** a cartoon avatar launching straight up, with a huge **"+1 JUMP"** in yellow and a dark outline. Use bright, saturated colors. No small text.
- **Thumbnail 1 (1920×1080):** a tiny avatar near the ground next to a tower of islands disappearing into space, with the caption **"JUMP 1,000,000 STUDS?!"** Make 2 or 3 versions and A/B test them; the Creator Dashboard lets you upload several thumbnails.
- **Thumbnail 2:** a gameplay screenshot from The Summit with the jump counter visible.

## 3. Short-form videos (TikTok / YouTube Shorts / Reels)
Post 1 video a day for the first 14 days. Make each one 15–25 seconds long and vertical, with the hook in the first second.

1. **"Every second I jump +1 higher"**: a time-lapse from 50 jump to The Summit, with a counter overlay. Final frame: "Game: Sky Jump +1 Jump".
2. **"POV: you got 1 jump short of the summit"**: a fail clip, then a cut to a win. People rewatch and comment on near misses.
3. **"Rebirth 0 vs Rebirth 10"**: a side-by-side race.
4. **"Can I reach the top before my mom says dinner"**: a challenge format.
5. **"New code just dropped"**: drop a code that only appears in the video (add it to `Config.CODES` the same day). This gives viewers a reason to open the game right away.

Caption template: `this roblox game is so addicting 😭 code: <CODE> #roblox #robloxgames #obby`

## 4. Paid ads (only once the numbers are good)
Use **Roblox Ads Manager** (Creator Dashboard → Ads). Run *Sponsored Experience* campaigns aimed at the ages and devices that match your game.
- Start with a small test budget for 3 days. **Don't scale up unless** your D1 retention and average session time are holding up in the Creator Dashboard analytics. Paying for traffic to a game that loses players wastes money.
- Use the best-performing thumbnail from step 2 as the ad image.
- I don't know current ad pricing, so check Ads Manager for real costs before you commit Robux.

## 5. Community
- Create a **Roblox group** and a **Discord** server. Put the links in the description.
- Turn on Roblox's social links on the experience page.
- Reply to every comment on your early videos. Comments push videos further.

## 6. Update cadence (this is what keeps a game growing)
| Week | Update | New code |
|---|---|---|
| 1 | Launch | RELEASE, SKYHIGH |
| 2 | 5 new islands + new top stage | ISLANDS |
| 3 | Trails shop (spend Wins) | TRAILS |
| 4 | Pets that boost jump gain | PETS |

Each update is a reason to post a video and change the title tag to `[UPDATE]`.

## 7. Numbers to watch (Creator Dashboard → Analytics)
- **D1 retention**: if this is low, fix the first 5 minutes before spending any more on ads.
- **Average session time**: if players leave too early, the first islands are too slow or too easy.
- **Visits from Home / Recommended**: when this starts rising by itself, the algorithm has picked you up. That's when to put more money into ads.
